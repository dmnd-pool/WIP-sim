# Technical terms

Use these terms consistently in the catalogue and simulator specification.
Product names and code identifiers retain their original spelling.

| Term | Meaning |
| --- | --- |
| ASIC | A chip designed for a specific computation |
| artifact | A saved file with a source record and checksum |
| board revision | A specific version of a physical board |
| bootloader | Software that starts the operating system or main firmware |
| control board | The board that runs control software and communicates with hashboards |
| device | The complete miner or a separately identified mining product |
| device tree | Data that describes hardware to a supported operating system |
| discovery record | A search lead that still needs verification |
| emulator | Software that reproduces an execution interface for other software |
| evidence | A source, measurement, or test that supports a claim |
| firmware | Software supplied for a device or board |
| FPGA | A chip with programmable digital logic |
| hashboard | A board that contains mining chips and their support circuits |
| hash rate | The number of hash trials per second |
| host | The computer that runs the simulator |
| image | A file that represents firmware, a filesystem, or storage contents |
| management API | An interface used to read or control a miner |
| manifest | A record of a file's identity, origin, size, and checksum |
| model | A named product; also a mathematical representation when explicitly stated |
| nonce | A variable value used in a proof-of-work search |
| OEM | The original equipment manufacturer |
| pool | A service that supplies mining work and receives results |
| profile | A complete selection of hardware, firmware, and test settings |
| proof of work | A computation whose result meets an algorithm's acceptance rule |
| PSU | Power supply unit |
| recovery image | An image used to restore a device's bootable software |
| relationship | A directed claim that connects two catalogue entities |
| share | A work result that meets the pool's target |
| simulator | Software that models a device's behavior under stated assumptions |
| snapshot | A saved state of a source repository or public index |
| source code | Program text used to build software |
| source record | A citation and access record for evidence |
| target | The acceptance limit for a proof-of-work result |
| trace | A recorded sequence of events and interface data |
| vendor-claimed | The supplier states support; this collection has not tested it |

## Writing method

New guide text uses short sentences, active verbs, and one term for each concept.
Procedures use direct instructions. Descriptions explain one topic at a time.
Technical terms appear in the table above.

The reference is ASD-STE100 Issue 9, dated 2025-01-15.
The original standard is saved for local reference.
No formal STE compliance certificate or complete dictionary audit is claimed.
Original vendor documents and quoted identifiers retain their source wording.
