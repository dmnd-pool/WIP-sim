# English translations

Original files remain unchanged.
English companions are stored separately.
Each record states the source, method, review status, and translation coverage.

A full document translation and a translated appendix are different results.
An English vendor edition can differ from another language edition.
The register preserves that uncertainty.

Code, protocol bytes, filenames, register names, and binary payloads are not translated.
Text in images can require OCR and manual review.
OCR confidence is not a guarantee of correctness.
