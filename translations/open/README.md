# English documents for the open-mining archive

The original repository archives stay unchanged.
Each folder contains the original text, an English document, and a provenance record.
Use `catalog/parts/open/translation-index.jsonl` to find these records.

The LVGL readme files have an English version in the same source archive.
The archive stores that version as the English companion for Chinese and Portuguese text.
The two versions have not had a word-for-word equivalence review.
These companion files cover the captured NerdAxe, BAP-GT-TOUCH, and Jingle source trees.
The Jingle originals match the inspected NerdAxe document bytes exactly.

The Pinyin input-method guide already has English and Chinese prose.
Its English copy removes the duplicate Chinese prose blocks.
The Chinese dictionary strings remain unchanged. They are functional example data.

The GMiner policy and licence already contain a publisher English translation.
The English copy contains that translation.
The publisher states that the Russian text takes precedence.
These GMiner files are outside the Bitcoin ASIC scope.

Four NMAxe HTML files contain Chinese comments or accessibility labels.
Their English copies translate all detected Chinese prose.
Code and identifiers stay unchanged. The copies use `.txt` filenames and are not build inputs.
The assistant made these translations. They have not had an independent language review.

The language scan checks CJK and Cyrillic text in small text documents.
It also checks known localised LVGL readme files.
It is not a complete review of every PDF, comment, UI string, or archive member.
Unreviewed material remains a documented gap.
Do not translate binary files, source identifiers, protocol fields, or checksum data.

The EEPROM format guide and board table from Alex20129/eeprom_tool have full English prose translations in `eeprom-eeprom_format/` and `eeprom-hashboards/`. The original table says to check and complete it. Its disputed model and chip claims are preserved as source claims.
